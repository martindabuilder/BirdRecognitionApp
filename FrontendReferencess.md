---- BIRD PHOTOS ----

[Wikimedia commons](https://commons.wikimedia.org/wiki/Main_Page), particulary their [API](https://www.mediawiki.org/wiki/API:Imageinfo) is used to fetch the corresponding bird photos, without the need to download naything locally.



---- BIRD HABITAT MAP:

[INaturalist Open Range Map Dataset](https://www.inaturalist.org/pages/range_maps) is used as the primary source of expected habitats for the birds. For it specifically im using their[API v1](https://api.inaturalist.org/v1/docs/).
[Leaflet](https://leafletjs.com/#:~:text=Leaflet%20is%20the%20leading%20open,performance%20and%20usability%20in%20mind.) is used to actually turn the iNaturalist habitat data into an actual map to be displayed.
